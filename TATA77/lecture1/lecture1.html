Inledning

Vi börjar med en funktion som beskriver en koncentrerad mängd massa.

Titta på vad som händer när n blir större.

ρₙ(x) = { n,   |x| ≤ 1/(2n) }

och ρₙ(x) = 0 annars.

n = 1
bredd = 1.000
höjd = 1.000
area = 1.000

Fundera

1. Vad händer med bredden när n ökar?

2. Vad händer med höjden?

3. Vad händer med arean?

4. För ett fast x ≠ 0 — vad verkar hända med ρₙ(x)?

5. Vad händer vid x = 0?

6. Kan ρₙ konvergera till en vanlig funktion?

Något konstigt händer: massan koncentreras allt mer kring x = 0, men den totala massan är fortfarande 1.

Hur beskriver man matematiskt något som koncentreras till en punkt?

Funktionsrum och konvergensbegrepp

Innan vi går vidare behöver vi tänka lite på vad det egentligen betyder att en följd av funktioner konvergerar.

Det finns nämligen flera olika sätt som funktioner kan närma sig varandra.

fₙ(x) = xⁿ

Betrakta fₙ på intervallet [0,1].

n = 1

Titta på grafen

1. Vad verkar hända när n blir större?

2. Vad händer för ett fast 0 ≤ x < 1?

3. Vad händer vid x = 1?

4. Vilken funktion verkar vara punktvis gräns?

5. Verkar funktionerna bli “nära” varandra överallt samtidigt?

‖f‖∞ = sup |f(x)|

Ett sätt att mäta hur stor en funktion är är alltså att titta på dess största absoluta värde.

Viktig idé

När vi skriver fₙ → f måste vi egentligen fråga:

På vilket sätt konvergerar fₙ mot f?

Detta blir viktigt när vanlig punktvis konvergens inte längre beskriver det vi vill beskriva.

Testfunktioner och distributioner

Kanske behöver vi inte fråga vad u(x) är i varje punkt.

Vi kan istället fråga hur u reagerar när vi testar den med en funktion φ.

⟨u, φ⟩ = ∫ u(x)φ(x) dx
⟨u, φ⟩ = 0.000

Experimentera

1. Flytta φ. Vad händer med ⟨u,φ⟩?

2. Vad händer när φ placeras där u är stor?

3. Vad händer där u är nära noll?

4. Vad tror du händer om φ byter tecken?

5. Vad verkar integralen egentligen mäta?

Tänk på φ som ett slags filter eller förstoringsglas.

Genom att välja olika testfunktioner kan vi undersöka olika egenskaper hos u.

⟨δ, φ⟩ = φ(0)

Delta behöver alltså inte beskrivas genom ett vanligt punktvärde.

Fundera

6. Vad gör δ med testfunktionen?

7. Är δ en vanlig funktion?

8. Varför kan det vara mer praktiskt att beskriva δ genom vad den gör?

Restriktion av distributioner

Hittills har vi betraktat funktioner på hela vårt område.

Men ibland vill vi bara undersöka vad som händer i en del av området.

Ω = (−1, 1)

Tänk att vi bara är intresserade av vad som händer inne i Ω.

φ:s centrum = 0.00
ligger i Ω: ja

Fundera

1. Vad betyder det intuitivt att “bara titta på u inne i Ω”?

2. Vad händer när φ ligger helt inne i Ω?

3. Vad händer när φ flyttas utanför Ω?

4. Varför är testfunktionens stöd viktigt?

5. Kan två distributioner vara olika utanför Ω men ändå se likadana ut när vi bara undersöker Ω?

För en vanlig funktion känns detta ganska naturligt: vi begränsar helt enkelt funktionen till området.

För distributioner uttrycker vi samma idé genom vilka testfunktioner vi får använda.

Konvergens av distributioner

Nu kan vi återvända till problemet från början.

Istället för att titta på ρₙ(x) punkt för punkt undersöker vi hur ρₙ verkar på en testfunktion.

⟨ρₙ, φ⟩ = n ∫−1/(2n)1/(2n) φ(x) dx
n = 1
⟨ρₙ, φ⟩ = 0.00000
φ(0) = 1.00000
skillnad = 0.00000

Titta noga

1. Vad händer med ρₙ när n blir större?

2. Vad händer med ⟨ρₙ,φ⟩?

3. Vad händer med skillnaden mellan ⟨ρₙ,φ⟩ och φ(0)?

4. Vilket objekt verkar vara gränsen?

ρₙ → δ

i distributionsmening.

uₙ → u

om

⟨uₙ, φ⟩ → ⟨u, φ⟩

för alla testfunktioner φ.

Varför behövde vi gå via testfunktioner istället för att bara titta på punktvärden?
